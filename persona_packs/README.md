# Persona Packs

`persona_packs/` is a working area for per-person likeness development and production planning.

Use `python .\tools\create_persona_pack.py "Person Name"` to create a new scaffold.

Each pack contains:

- `manifest.json` for dialogue/voice behavior fields,
- `references/README.md` as a placeholder for private or licensed source media,
- `appearance-notes.md` for face/clothing translation notes,
- `voice-notes.md` for speaking-style and consent/licensing notes,
- `creation-kit-notes.md` for in-game implementation checkpoints.

## Asset Safety Rules

- Keep raw likeness references private unless you have rights to distribute them.
- Do not commit private photos, paid model files, or unlicensed media.
- Commit notes and manifests first; add media only when legal/consent status is clear.
